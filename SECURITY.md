# Security Policy

## Supported Versions

Only the latest release of `indicatorts` on npm receives fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Instead, report them privately through GitHub's [private vulnerability reporting](https://github.com/cinar/indicatorts/security/advisories/new) for this repository. Please include:

- the affected version,
- a description of the issue and its impact,
- steps or a minimal example to reproduce it.

## Maintenance Status

This project is no longer actively developed, so reports may not receive a timely response, and a fix is not guaranteed. If you depend on a fix, you are welcome to fork the project under the [MIT License](LICENSE.md).
