# Volatility Strategy Examples

The examples in this directory illustrate how developers can compose volatility indicator calculations into trading signals.

> **Disclaimer:** The examples provided here are strictly for educational and research purposes. They do not constitute investment advice or trading recommendations.

**NOTE:** All configuration objects for all example strategies are optional. If no configuration object is passed, default values will be used.

## Acceleration Bands Strategy

The [accelerationBandsStrategy](./accelerationBandsStrategy.ts) demonstrates how to use values generated by the [Acceleration Bands](../../src/indicator/volatility/README.md#acceleration-bands-ab) indicator to provide a BUY action when closing is greater than or equal to Upper Band, and a SELL action otherwise.

```TypeScript
import { abStrategy } from '../examples/volatility/accelerationBandsStrategy';

const defaultConfig = { period: 20, multiplier: 4 };
const actions = abStrategy(asset, defaultConfig);
```

## Bollinger Bands Strategy

The [bollingerBandsStrategy](./bollingerBandsStrategy.ts) demonstrates how to use values generated by the [Bollinger Bands](../../src/indicator/volatility/README.md#bollinger-bands-bb) indicator to provide a SELL action when asset closing is above Upper Band, a BUY action when closing is below Lower Band, and HOLD otherwise.

```TypeScript
import { bbStrategy } from '../examples/volatility/bollingerBandsStrategy';

const defaultConfig = { period: 20 };
const actions = bbStrategy(asset, defaultConfig);
```

## Projection Oscillator Strategy

The [projectionOscillatorStrategy](./projectionOscillatorStrategy.ts) demonstrates how to use values generated by the [Projection Oscillator (PO)](../../src/indicator/volatility/README.md#projection-oscillator-po) indicator to provide a BUY action when PO is above Smoothed PO, and a SELL action when PO is below Smoothed PO.

```TypeScript
import { poStrategy } from '../examples/volatility/projectionOscillatorStrategy';

const defaultConfig = { period: 14, smooth: 3 };
const actions = poStrategy(asset, defaultConfig);
```
