## Absolute Price Oscillator Strategy

The [absolutePriceOscillatorStrategy](./absolutePriceOscillatorStrategy.ts) demonstrates how to use values generated by the [Absolute Price Oscillator (APO)](../../src/indicator/trend/README.md#absolute-price-oscillator-apo) indicator to provide a BUY action when APO is greater than zero, and a SELL action when APO is less than zero.

```TypeScript
import { apoStrategy } from '../examples/trend/absolutePriceOscillatorStrategy';

const defaultConfig = { fast: 14, slow: 30 };
const actions = apoStrategy(asset, defaultConfig);
```

## Aroon Strategy

The [aroonStrategy](./aroonStrategy.ts) demonstrates how to use values generated by the [Aroon Indicator](../../src/indicator/trend/README.md#aroon) to provide a BUY action when Aroon Up is greater than Aroon Down, and a SELL action when Aroon Down is greater than Aroon Up.

```TypeScript
import { aroonStrategy } from '../examples/trend/aroonStrategy';

const defaultConfig = { period: 25 };
const actions = aroonStrategy(asset, defaultConfig);
```

## KDJ Strategy

The [kdjStrategy](./kdjStrategy.ts) demonstrates how to use values generated by the [Random Index (KDJ)](../../src/indicator/trend/README.md#random-index-kdj) indicator to provide a BUY action when %K crosses above %D and is below 20, and a SELL action when %K crosses below %D and is above 80.

```TypeScript
import { kdjStrategy } from '../examples/trend/kdjStrategy';

const defaultConfig = { rPeriod: 9, kPeriod: 3, dPeriod: 3 };
const actions = kdjStrategy(asset, defaultConfig);
```

## MACD Strategy

The [macdStrategy](./macdStrategy.ts) demonstrates how to use values generated by the [Moving Average Convergence Divergence (MACD)](../../src/indicator/trend/README.md#moving-average-convergence-divergence-macd) indicator to provide a BUY action when MACD Line crosses above Signal Line, and a SELL action when MACD Line crosses below Signal Line.

```TypeScript
import { macdStrategy } from '../examples/trend/macdStrategy';

const defaultConfig = { fast: 12, slow: 26, signal: 9 };
const actions = macdStrategy(asset, defaultConfig);
```

## Parabolic SAR Strategy

The [parabolicSARStrategy](./parabolicSarStrategy.ts) demonstrates how to use trend directions generated by the [Parabolic SAR](../../src/indicator/trend/README.md#parabolic-sar-psar) indicator to provide a BUY action when trend is RISING, and a SELL action when trend is FALLING.

```TypeScript
import { psarStrategy } from '../examples/trend/parabolicSarStrategy';

const defaultConfig = { step: 0.02, max: 0.2 };
const actions = psarStrategy(asset, defaultConfig);
```

## Volume Weighted Moving Average (VWMA) Strategy

The [vwmaStrategy](./vwmaStrategy.ts) demonstrates how to combine SMA and VWMA indicators into a moving average crossover signal, providing a BUY action when VWMA is above SMA, and a SELL action when VWMA is below SMA.

```TypeScript
import { vwmaStrategy } from '../examples/trend/vwmaStrategy';

const defaultConfig = { period: 20 };
const actions = vwmaStrategy(asset, defaultConfig);
```
