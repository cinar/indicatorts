**NOTE:** All configuration objects for all example strategies are optional. If no configuration object is passed, default values will be used.

## Awesome Oscillator Strategy

The [awesomeOscillatorStrategy](./awesomeOscillatorStrategy.ts) demonstrates how to use the values generated by the [Awesome Oscillator](../../src/indicator/momentum/README.md#awesome-oscillator-ao) indicator to provide a SELL action when AO is below zero, and a BUY action when AO is above zero.

```TypeScript
import { aoStrategy } from '../examples/momentum/awesomeOscillatorStrategy';

const defaultConfig = { fast: 5, slow: 34 };
const actions = aoStrategy(asset, defaultConfig);
```

## Ichimoku Cloud Strategy

The [ichimokuCloudStrategy](./ichimokuCloudStrategy.ts) demonstrates how to use the values generated by the [Ichimoku Cloud](../../src/indicator/momentum/README.md#ichimoku-cloud) indicator to provide a BUY action when Leading Span A is greater than Leading Span B, and a SELL action when Leading Span A is less than Leading Span B.

```TypeScript
import { ichimokuCloudStrategy } from '../examples/momentum/ichimokuCloudStrategy';

const defaultConfig = { short: 9, medium: 26, long: 52, close: 26 };
const actions = ichimokuCloudStrategy(asset, defaultConfig);
```

## RSI 2 Strategy

The [rsi2Strategy](./rsi2Strategy.ts) demonstrates how to use the values generated by the [Relative Strength Index (RSI)](../../src/indicator/momentum/README.md#relative-strength-index-rsi) indicator to provide a BUY action when 2-period RSI moves below 10 (oversold threshold), and a SELL action when 2-period RSI moves above 90 (overbought threshold).

```TypeScript
import { rsi2Strategy } from '../examples/momentum/rsi2Strategy';

const actions = rsi2Strategy(asset);
```

## Stochastic Oscillator Strategy

The [stochasticOscillatorStrategy](./stochasticOscillatorStrategy.ts) demonstrates how to use the values generated by the [Stochastic Oscillator](../../src/indicator/momentum/README.md#stochastic-oscillator-stoch) indicator to provide a BUY action when %K and %D are less than or equal to 20, and a SELL action when %K and %D are greater than or equal to 80.

```TypeScript
import { stochStrategy } from '../examples/momentum/stochasticOscillatorStrategy';

const defaultConfig = { kPeriod: 14, dPeriod: 3 };
const actions = stochStrategy(asset, defaultConfig);
```

## Williams R Strategy

The [williamsRStrategy](./williamsRStrategy.ts) demonstrates how to use the values generated by the [Williams R](../../src/indicator/momentum/README.md#williams-r-willr) indicator to provide a BUY action when Williams %R is below or equal to -80, and a SELL action when it is above or equal to -20.

```TypeScript
import { willRStrategy } from '../examples/momentum/williamsRStrategy';

const defaultConfig = { period: 14 };
const actions = willRStrategy(asset, defaultConfig);
```
