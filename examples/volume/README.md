**NOTE:** All configuration objects for all example strategies are optional. If no configuration object is passed, default values will be used.

## Chaikin Money Flow Strategy

The [chaikinMoneyFlowStrategy](./chaikinMoneyFlowStrategy.ts) demonstrates how to use values generated by the [Chaikin Money Flow (CMF)](../../src/indicator/volume/README.md#chaikin-money-flow-cmf) indicator to provide a BUY action when CMF is less than zero, and a SELL action when CMF is greater than zero.

```TypeScript
import { cmfStrategy } from '../examples/volume/chaikinMoneyFlowStrategy';

const defaultConfig = { period: 20 };
const actions = cmfStrategy(asset, defaultConfig);
```

## Ease of Movement Strategy

The [easeOfMovementStrategy](./easeOfMovementStrategy.ts) demonstrates how to use values generated by the [Ease of Movement (EMV)](../../src/indicator/volume/README.md#ease-of-movement-emv) indicator to provide a BUY action when EMV is greater than zero, and a SELL action when EMV is less than zero.

```TypeScript
import { emvStrategy } from '../examples/volume/easeOfMovementStrategy';

const actions = emvStrategy(asset, defaultConfig);
```

## Force Index Strategy

The [forceIndexStrategy](./forceIndexStrategy.ts) demonstrates how to use values generated by the [Force Index (FI)](../../src/indicator/volume/README.md#force-index-fi) indicator to provide a BUY action when FI is greater than zero, and a SELL action when FI is less than zero.

```TypeScript
import { fiStrategy } from '../examples/volume/forceIndexStrategy';

```

## Money Flow Index Strategy

The [moneyFlowIndexStrategy](./moneyFlowIndexStrategy.ts) demonstrates how to use values generated by the [Money Flow Index (MFI)](../../src/indicator/volume/README.md#money-flow-index-mfi) indicator to provide a SELL action when MFI is greater than or equal to 80, and a BUY action otherwise.

```TypeScript
import { mfiStrategy } from '../examples/volume/moneyFlowIndexStrategy';

const defaultConfig = { period: 14 };
const actions = mfiStrategy(asset, defaultConfig);
```

## Negative Volume Index Strategy

The [negativeVolumeIndexStrategy](./negativeVolumeIndexStrategy.ts) demonstrates how to use values generated by the [Negative Volume Index (NVI)](../../src/indicator/volume/README.md#negative-volume-index-nvi) indicator to provide a BUY action when NVI is less than its 255-period EMA, and a SELL action when NVI is greater than its 255-period EMA.

```TypeScript
import { nviStrategy } from '../examples/volume/negativeVolumeIndexStrategy';

const defaultConfig = { start: 1000, period: 255 };
const actions = nviStrategy(asset, defaultConfig);
```

## Volume Weighted Average Price Strategy

The [volumeWeightedAveragePriceStrategy](./volumeWeightedAveragePriceStrategy.ts) demonstrates how to use values generated by the [Volume Weighted Average Price (VWAP)](../../src/indicator/volume/README.md#volume-weighted-average-price-vwap) indicator to provide a BUY action when closing price is below VWAP, and a SELL action when closing price is above VWAP.

```TypeScript
import { vwapStrategy } from '../examples/volume/volumeWeightedAveragePriceStrategy';

const defaultConfig = { period: 14 };
const actions = vwapStrategy(asset, defaultConfig);
```
